# 🛠️ AutoHotkey

**AutoHotkey** — свободно распространяемый язык для автоматизации выполнения задач в Microsoft Windows.

> Тут будут собраны мои скрипты для оптимизации личного пространства.

---

## 📋 Назначение файлов
| Имя файла             | Назначение                                                              |
|-----------------------|-------------------------------------------------------------------------|
| MassScript            | Главный скрипт с массвой возможностей. Активно использую.               |
|                       |                                                                         |
| AClock + messages.txt | Кастомный тонконастраиваемый будильник. Не стал доделывать.             |

## 💡 Хоткеи из `MassScript.ahk`

### 📦 Взаимодействие с программами
| AHK-синтаксис     | Привычный формат         | Описание                           |
|-------------------|--------------------------|------------------------------------|
| `MButton & 1`     | `MButton + 1`            | Открыть Yandex Browser             |
| `MButton & 2`     | `MButton + 2`            | Открыть Yandex mini-app GTP        |
|                   |                          |                                    |
| `MButton & 3`     | `MButton + 3`            | Открыть Obsidian                   |
| `MButton & 4`     | `MButton + 4`            | Открыть Obsidian Style             |
| `MButton & a`     | `MButton + a`            | Свернуть/развернуть Android Studio |
|                   |                          |                                    |
| `MButton & q`     | `MButton + q`            | Открыть Блокнот                    |
| `MButton & q (x2)`| `MButton + q`            | Открыть Notepad++                  |
|                   |                          |                                    |
| `^+MButton`       | `Ctrl + Shift + MButton` | Закрыть приложение                 |

### 📝 Работа со строками
| AHK-синтаксис     | Привычный формат     | Описание                                              |
|-------------------|----------------------|-------------------------------------------------------|
| `^MButton`        | `Ctrl + MButton`     | Переключить текст между однострочным и многострочным  |

### 🪟 Работа с окнами
| AHK-синтаксис     | Привычный формат     | Описание                                  |
|-------------------|----------------------|-------------------------------------------|
| `MButton & Tab`   | `MButton + Tab`      | Переход к полю ввода [GPT]                |
| `MButton & z`     | `MButton + z`        | Закрепить окно                            |
|                   |                      |                                           |
| `MButton & s`     | `MButton + s`        | Общее сворачивание/разворачивание окон    |
| `!MButton`        | `Alt + MButton`      | Свернуть окно под курсором                |
| `~*Altx2`         | `Alt x2`             | Открыть последнее свернутое окно          |
| `#MButton`        | `Win + MButton`      | Развернуть/Свернуть окно под курсором     |
|                   |                      |                                           |
| `~MButton & g`    | `MButton + g`        | Расширить окно вправо на 10%              |
| `~MButton & h`    | `MButton + h`        | Расширить окно влево на 10%               |
| `~MButton & j`    | `MButton + j`        | Расширить окно вниз на 10%                |
| `~MButton & y`    | `MButton + y`        | Расширить окно вверх на 10%               |
|                   |                      |                                           |
| `~MButton & f`    | `MButton + f`        | Переместить окно вправо                   |
| `~MButton & k`    | `MButton + k`        | Переместить окно вниз                     |
| `~MButton & u`    | `MButton + u`        | Переместить окно вверх                    |
| `~MButton & n`    | `MButton + n`        | Переместить окно влево                    |
|                   |                      |                                           |
| `~MButton & Space`| `MButton + Space`    | Погасит/Включит экран под мышкой          |
